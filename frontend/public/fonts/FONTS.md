# Raphael landing typefaces

The landing uses original, unmodified WOFF2 files obtained from Fontshare's
official CSS API and CDN on October 5, 2026. The adjacent `.source.css` files
preserve the original CDN URLs and face metadata. No font was edited,
subsetted, renamed internally, or converted into logo paths.

| Typeface | Weight | Role | Source stylesheet |
| --- | --- | --- | --- |
| Sentient | 400 | Large headings | https://api.fontshare.com/v2/css?f[]=sentient@400&display=swap |
| Switzer | 400 | Reading and navigation | https://api.fontshare.com/v2/css?f[]=switzer@400&display=swap |
| Switzer | 500 | Buttons and artifact titles | https://api.fontshare.com/v2/css?f[]=switzer@500&display=swap |
| Telma | 500 | Raphael wordmark | https://api.fontshare.com/v2/css?f[]=telma@500&display=swap |

Foundry: Indian Type Foundry. Fontshare's official license and terms:
https://www.fontshare.com/licenses/itf-ffl

IBM Plex Mono is the project's existing self-hosted evidence face. Older
Instrument Sans and Newsreader assets remain for the earlier design work;
the current landing does not request them.
