# Official brand assets

These marks come from the respective official brand resources:

- GitHub white and black Invertocat: https://brand.github.com/GitHub_Logos.zip — https://brand.github.com/foundations/logo
- Docker Ocean Blue mark: https://www.docker.com/static/Docker-Logos-1.zip — https://www.docker.com/company/newsroom/media-resources/
- Kubernetes: https://raw.githubusercontent.com/cncf/artwork/main/projects/kubernetes/icon/color/kubernetes-icon-color.svg
- Supabase: https://raw.githubusercontent.com/supabase/supabase/master/packages/common/assets/images/supabase-logo-icon.svg — https://supabase.com/brand-assets

Marks belong to their respective owners and represent the named integrations. The Docker SVG retains its official path and color, with explicit dimensions and inline fill for standalone image rendering. Ignis uses the package icon and Dispatch uses paper-plane-tilt from Phosphor Icons (https://phosphoricons.com/), via the installed @phosphor-icons/core package. Their fills are white. See PHOSPHOR-LICENSE.txt. Raphael uses a dedicated white copy of the local logo artwork.
