# Raphael roadmap

## Planned: custom context and tool loop

This is a separate roadmap direction, not the current workflow shown on the landing page. The execution strategy is not final.

The proposed custom harness would gather relevant evidence into a bounded working context, choose permitted tools, and update its hypotheses from the results:

1. Build context.
2. Reason.
3. Choose a permitted tool.
4. Execute.
5. Observe and update.
6. Validate or stop.

Existing structured run state and bounded patch retries are current foundations. The broader custom harness is planned and is not available as shown.
